# 魔域连GAN

这是基于 GAN 魔方星球（CubeStation）的 Android 改版。手机通过蓝牙直连魔域 V10 AI（MoYu32 协议），不需要电脑、开发板或第二部手机。

1. 下载 [最新通用 APK](https://github.com/CadenAlgo/moyuconnectganapp/releases/latest) 并安装。
2. 打开应用，用手机号登录，并允许蓝牙或附近设备权限。
3. 转动一下魔方唤醒它，在「设备连接」中添加设备。状态不同步时，先把实体魔方复原，再点「状态重置」。

通用包包含 ARM 32 位和 64 位库。手机号登录、魔域魔方连接和状态重置已在 OPPO Reno14（ColorOS 16）上验证。登录、在线比赛和榜单仍使用魔方星球服务。微信和 QQ 登录会校验应用身份，请使用手机号。

各版本的改动和实测反馈见 Releases。

## v0.11 更新

- 适配魔方星球 11 月 12 日至 13 日的资源热更新（已验证 `0.202611131111`）。v0.10 遇到这批资源后，首页商城、任务和活动入口会重新出现。
- OPPO Reno14 覆盖安装及重开实测，原账号可直接进入，首页恢复精简，全民竞技只显示擂台赛和排位赛，两者均可进入，排位榜可加载。比赛未实际开局。
- 通用包为 351.97 MiB，保留 ARM 32 位和 64 位。以后官方如果再次替换首页或竞技页资源，可能还需要更新补丁。

## v0.10 更新

- 去掉首页右下角的 AI 机器人和顶部金币、点券区域的浅白框。OPPO Reno14 实测确认这两处已消失。
- 实际移除 132 个内置资源包，主要涉及商城、签到、活动和皮肤装饰特效。通用 APK 从 369.77 MiB 降到 349.24 MiB，仍包含 ARM 32 位和 64 位库。
- 保留设备连接、状态重置、擂台赛、排位赛、榜单和公式练习入口。在线功能继续使用官方服务。

包内还包含 Unity 引擎和比赛、练习共用的字体、模型及界面资源。覆盖安装后，手机此前下载的资源缓存可能仍占空间。
