# 魔域连GAN

这是基于 GAN 魔方星球（CubeStation）的 Android 改版。手机通过蓝牙直连魔域 V10 AI（MoYu32 协议），不需要电脑、开发板或第二部手机。

1. 打开 [最新版本](https://github.com/CadenAlgo/moyuconnectganapp/releases/latest)，选精简版或原界面版的 APK 安装。
2. 打开应用，用手机号登录，并允许蓝牙或附近设备权限。
3. 转动一下魔方唤醒它，在「设备连接」中添加设备。状态不同步时，先把实体魔方复原，再点「状态重置」或右侧「重置」。
4. 在游戏画面右侧点「型号」，选中要使用的 GAN 型号。魔方已连接时可以直接切换。

通用包包含 ARM 32 位和 64 位库。手机号登录、魔域魔方连接和状态重置已在 OPPO Reno14（ColorOS 16）上验证。登录、在线比赛和榜单仍使用魔方星球服务。微信和 QQ 登录会校验应用身份，请使用手机号。

各版本的改动和实测反馈见 Releases。

## v0.16 更新

- [精简版](https://github.com/CadenAlgo/moyuconnectganapp/releases/download/v0.16/MoYuConnectGAN-v0.16-lite-universal.apk)（`lite`，354.76 MiB）隐藏首页签到、商城、任务及活动推广；[原界面版](https://github.com/CadenAlgo/moyuconnectganapp/releases/download/v0.16/MoYuConnectGAN-v0.16-full-universal.apk)（`full`，369.79 MiB）保留这些入口。两版均为 ARM 32 位和 64 位通用包。
- 适配 11 月 24 日的官方资源更新，修复精简版活动入口重新出现的问题。保留登录、设备连接、公式练习、擂台赛、排位赛及榜单。
- 右侧「重置」支持在擂台赛打乱过程中重置状态。先把实体魔方手动还原，再点「已还原，重置」，随后按重新计算的打乱提示继续。修正一类重复蓝牙通知造成软件状态多转一步的问题。
- 擂台赛复原后保留完整成绩页，显示真实用时、步数、TPS、分步分析和最近五把，并保留录像入口。增加可选的「删除本把」，不用每把点提交，也不会每把弹出选择框。
- 停留在成绩页时，本把成绩暂不上传。主动点击「删除本把」并确认，会取消本把上传并返回擂台赛；照常来回转动进入下一把，或者点原来的「返回」，则提交本把真实成绩，删除入口随之关闭。修复之前需要额外点「下一把」、退出困难的问题。
- **删除仅适用于当前尚未上传的一把，不支持删除官方服务器上已经保存的历史成绩。**没有发现并验证可用的服务端删除接口。本把暂存于应用进程中，强制结束应用会丢失这条待提交记录。
- 成功提交后主动刷新擂台赛记录和统计，仍需等待官方服务器响应。保留原始成绩、步数和录像数据，不提供改写计时或伪造成绩的功能。
- 「型号」「重置」「删除本把」统一为更小的浅蓝渐变圆角按钮；删除入口放在成绩页右下角。两版均去掉成绩页底部的 AI 分析提示、按钮和机器人。
- 沿用六款 GAN Gen2 型号切换及 V10 AI 真实姿态跟随。原账号可随同包名覆盖安装保留，微信、QQ 登录仍请改用手机号登录。

精简版已在 OPPO Reno14 / ColorOS 16 实测：用户确认打乱途中重置与继续打乱正常，完整成绩页、可选删除及正常继续流程可用。另已检查返回退出、实际成绩上传后刷新、签名及双架构。原界面版使用相同蓝牙及成绩处理代码，未另做完整实机回归。安装包版本名为 `6.8-moyu.btD`，versionCode 为 120，校验值附在 Release 的 `SHA256.txt`。

## v0.13 更新

- [精简版](https://github.com/CadenAlgo/moyuconnectganapp/releases/download/v0.13/MoYuConnectGAN-v0.13-lite-universal.apk)（`lite`，351.98 MiB）隐藏签到、商城、任务及活动推广，保留设备连接、状态重置、公式练习、擂台赛、排位赛及榜单。可覆盖安装 v0.12「魔域蓝牙兼容」。
- [原界面版](https://github.com/CadenAlgo/moyuconnectganapp/releases/download/v0.13/MoYuConnectGAN-v0.13-full-universal.apk)（`full`，367.12 MiB）使用原版界面及活动资源，应用名为「魔域兼容原版」。可以与精简版并存，第一次打开需用手机号登录。
- 两版均包含 ARM 32 位和 64 位库，都支持在游戏右侧「型号」菜单切换六款 GAN Gen2 型号。v0.10 使用独立包名，可与新版并存。
- 支持威龙 V10 AI 的整颗魔方姿态跟随。修正实测反向的俯视旋转和前后俯仰，并按 GAN Gen2 的格式传递连续两组真实姿态。首次安装默认选 GAN12 UI，已有的型号设置会继续使用。
- 使用姿态跟随时，请选 GAN12 UI、GAN 356 i 3、GAN Mini UI FreePlay 或 GAN12 UI FreePlay，并在「设置 → 魔方」开启性能模式。可在「魔方练习 → 计时练习」转动整颗魔方检查效果。GAN 356 i Carry 和 Carry S 支持面转动。
- OPPO Reno14 实测精简版，使用威龙 V10 AI 和 GAN12 UI 在计时练习中确认三轴方向均与实体魔方一致。

## v0.12 更新

- 「型号」菜单支持六款 GAN Gen2 三阶魔方。保留 GAN 356 i Carry 和 GAN12 UI，新增 GAN 356 i Carry S、GAN 356 i 3、GAN Mini UI FreePlay 和 GAN12 UI FreePlay。
- 修复横屏展开菜单时选项挤在一起的问题。选项分行显示，屏幕高度不足时可以上下滚动。OPPO Reno14 已确认六个选项都能完整显示，并用威龙 V10 AI 在擂台赛页面验证了切换后能显示 GAN12 UI FreePlay。
- 沿用 v0.11 的精简界面，保留设备连接、状态重置、公式练习、擂台赛、排位赛及榜单。通用 APK 为 351.98 MiB，包含 ARM 32 位和 64 位库。

安装后应用显示为「魔域蓝牙兼容」，可与 v0.11「魔域连GAN」并存。已装过同包名的「魔域蓝牙兼容」测试版可以直接覆盖更新。首次安装需要用手机号登录。

## v0.10 更新

- 去掉首页右下角的 AI 机器人和顶部金币、点券区域的浅白框。OPPO Reno14 实测确认这两处已消失。

包内还包含 Unity 引擎和比赛、练习共用的字体、模型及界面资源。覆盖安装后，手机此前下载的资源缓存可能仍占空间。
